# Section 6.8: Cover Letter Customization

router mode: `task_6_8`

**Purpose:** create role-specific applications (see `section-2-cover-letter.md` for the full workflow; use this as the quick version).

1. Analyze the job description: employer needs, required skills, key priorities.
2. Select relevant experience: matching achievements, relevant projects, supporting examples.
3. Build letter structure: opening interest, relevant qualifications, evidence of impact, closing statement.
4. Customize company alignment: company-specific reasons, role-specific value.
5. Review quality: no generic statements, clear value proposition, professional tone.
